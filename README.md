# Huffman Tree Comparable (哈夫曼编码三种方案对比)

这是一个基于 C++ 实现的哈夫曼编码与解码系统。项目不仅实现了标准的哈夫曼压缩与解压，还重点对比了 **三种不同的哈夫曼树/字典存储方案**，通过实际数据验证了不同方案对文件空间占用和压缩率的影响。

## 🌟 核心功能 (Features)

- **基础功能**：读取文本文件，统计字符频率，构建哈夫曼树。
- **编码与解码**：支持将文本文件压缩为二进制编码文件（`.bin`），并能完美解码还原。
- **多方案对比**：实现了三种不同的树结构/字典持久化方案，并自动生成对比报告。
- **可视化输出**：支持将哈夫曼树结构打印为格式化文本（展示树形结构），以及将编码后的 01 序列分行打印。
- **交互式终端**：提供带有颜色和菜单的命令行界面，操作直观。

## 🧠 三种存储方案解析

本项目核心对比了以下三种方案的树结构保存大小与压缩效率：

1. **方案一（完整树结构）**：
   - 保存方式：先序优先遍历。每个节点记录 `(是否是叶子节点 flag, 权重 weight, 字符 ch)`。
   - 特点：保留所有信息（包括权值），但由于存储了权值（8字节），导致树文件较大。
2. **方案二（精简树结构）**：
   - 保存方式：在方案一基础上优化。仅记录 `(flag, 字符 ch)`，不保存权重。
   - 特点：解码时依靠树结构推导路径，去除了冗余的权值信息，树文件显著变小。
3. **方案三（规范哈夫曼编码 Canonical Huffman）**：
   - 保存方式：不保存树结构，仅保存字典表。每个字符记录 `(字符 ch, 编码长度 len)`。
   - 特点：**最节省空间**。通过长度和字符顺序，按固定算法推导出标准编码，树文件极小，且解码速度极快。

## 📂 项目结构 (File Structure)

- `main.cpp`：主程序入口，提供交互式菜单。
- `buildhfm.cpp` / `buildhfm.h`：哈夫曼树的构建（优先队列实现），以及核心数据结构定义。
- `saveHfmTree.cpp`：方案一与方案二的树结构序列化与反序列化。
- `canonical.cpp`：方案三（规范哈夫曼编码）的字典生成、保存、编码与解码。
- `encode.cpp` / `decode.cpp`：通用的编码与解码逻辑。
- `printCode.cpp`：将二进制文件转换为 01 字符串输出，方便查看。
- `compare.cpp`：一键运行三种方案，并对比文件大小、压缩率。
- `input.txt`：测试输入文件（马丁·路德·金演讲片段）。
- `hfm_tree_comparable.vcxproj`：Visual Studio 项目工程文件。

## 🚀 如何运行 (How to Run)

### 方法一：使用 Visual Studio (推荐)
1. 克隆本仓库到本地：`git clone https://github.com/free6543/hfm_tree_comparable.git`
2. 双击打开 `hfm_tree_comparable.vcxproj`。
3. 选择 `Debug` 或 `Release` 模式（建议 `x64`），点击“本地 Windows 调试器”运行。

### 方法二：使用命令行 (g++ 编译)
确保你的系统安装了 g++，在项目根目录下执行：
```bash
g++ main.cpp bulidhfm.cpp canonical.cpp compare.cpp decode.cpp encode.cpp printCode.cpp saveHfmTree.cpp -o hfm_app
./hfm_app
